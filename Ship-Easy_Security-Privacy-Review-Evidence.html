6Token encryption & encryption at rest

The monday user access token (and all config/credentials) is stored encrypted at rest in monday Secure Storage, keyed per account. Used server-side only, never returned to the frontend, sent only over TLS 1.2+, and auto-cleared if revoked. No own datastore → no separate at-rest implementation.

Evidence: src/services/account-store.ts

📎 Attach (optional): account-store.ts (SecureStorage usage)

7User data stored (what / why / where)

No separate application database. Configuration & credentials (OAuth token, board/column mapping, WhatsApp/Shiprocket credentials, Shopify domain, per-account webhook token) are stored encrypted in monday Secure Storage. Order/customer personal data (name, address, phone, email) is processed transiently to create records on the customer's own boards and fulfill the order — not persisted by us.

Text answer — no screenshot required.

8Permission scopes (least privilege)

  • me:read — identify the installing account to isolate each customer's data.
  • boards:read — read orders, line items, suppliers, and configuration.
  • boards:write — create the required boards/columns and write order/shipment/status data.

Only these three scopes are requested. Text answer — no screenshot required.

9Logging & retention (monday logger enabled)

Logs record account IDs, board/item IDs, order IDs, and steps/errors. No access tokens; phone numbers masked; error logs sanitized of request payloads. App writes to stdout, captured by monday-code — the monday logger is enabled (mapps code:logs). Retention: monday-code default.

Evidence: src/utils/log-safe.ts, maskPhone in invocable-actions.ts

📎 Attach: mapps code:logs output showing logs streaming

10Injection protection & input validation

No SQL / external DB. All monday API calls are parameterized with GraphQL variables — no user/external data string-interpolated into queries. Settings input is whitelisted, primitives only, trimmed, length-capped (4096). Shopify payloads validated for shape. Frontend output is HTML-encoded by React (no dangerouslySetInnerHTML).

Evidence: monday-service.ts, routes/settings.ts, shopify-controller.ts
